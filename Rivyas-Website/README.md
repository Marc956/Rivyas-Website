## GitHub Pages
1. Create a GitHub repository named `Rivyas-Website`.
2. Upload all files/folders from this repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide the Pages URL.

## Important before publishing
- Verify Rivyas contact details and service geography.
- Confirm that “EST. 2023” is approved for public use.
- Replace/augment generic content with real Rivyas product, fabric, production and client photography.
- Confirm actual minimum order quantities and lead times before publishing them.
- Review all product certifications and safety/sustainability claims before adding them.
- The contact form currently uses FormSubmit to send enquiries to the Rivyas email. Test it after deployment.
